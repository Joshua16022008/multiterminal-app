# Multiterminal – Benutzerhandbuch

*English in short: Multiterminal is a macOS desktop app (Electron) that runs many real terminals per project in one grid, each with its own mini browser, so you can run terminal agents side by side. The app interface and this handbook are currently in German.*

Multiterminal ist eine Desktop-App für macOS. Projekte stehen in einer Seitenleiste, pro Projekt laufen bis zu 30 echte Terminals im Raster, und jedes Terminal hat einen eigenen Mini-Browser. So lassen sich Terminal-Agenten wie Claude Code, Codex und Kimi Code nebeneinander betreiben.

Dieses Handbuch ist die einzige Quelle für die Hilfe in der App und für GitHub. Die Seiten sind Markdown-Dateien im selben Ordner. In der App öffnest du sie mit ⌘⇧H oder mit dem Knopf „?“ oben rechts.
